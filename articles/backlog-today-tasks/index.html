Backlogで「今日やること」だけを個人管理する方法

担当課題の一覧は長いのに、今日どこから始めるかが決まらない。そんなときは、チームの進捗と自分の一日の予定を分けて考えると整理しやすくなります。

01 / GUIDE

期限と今日の予定を分ける

期限はチームや顧客との約束で、今日の予定は自分の時間の使い方です。来週締切でも今日着手すべき課題はありますし、今日が期限でも相手からの返答を待っている課題もあります。

今日の一覧を作るためだけにBacklogの期限やステータスを変更すると、チームへの意味が変わってしまいます。共有情報はそのままに、個人の選択を別に持つ方法が適しています。

02 / GUIDE

朝に今日の仕事を選ぶ

  1. 期限が近い課題と新しいコメントを確認する。
  2. 今日使える時間を、会議や定例作業を除いて見積もる。
  3. 締切、他の人への影響、着手可能かどうかで候補を絞る。
  4. 選んだ課題を実際に取り組む順番に並べる。

例えば作業時間が3時間なら、1時間の修正と1時間の確認作業を選び、残りを連絡や割り込みに使う考え方もあります。件数を固定するより、作業の大きさに合わせて選びます。

03 / GUIDE

割り込みが来たら入れ替える

急な依頼は、既存の予定との入れ替えとして扱います。新しい仕事を追加するだけでは、その日の一覧が終わらないリストになります。何を翌日に回すかも同時に判断しましょう。

相手の返信を待つ間は、その課題を「待ち」として区別します。確認の連絡を今日行うなら、その時間を予定に含めます。待ち状態のすべてを今日の作業として抱える必要はありません。

04 / GUIDE

終業前に持ち越しを整理する

終わった課題は元のBacklogで必要な報告・更新を行います。「今日」から外すこととチームの課題を完了することは同じではありません。

残った課題は、見積もりが大きすぎたのか、割り込みがあったのか、着手条件が揃わなかったのかを確認します。翌日の一覧へ無条件に残さず、「次」「待ち」「あとで」へ整理し直すと、翌朝の判断が軽くなります。

05 / GUIDE

IssueDockの「今日」で個人の予定を持つ

IssueDockでは、個人ステータスの「次・待ち・あとで」と独立した「今日」を使えます。ピンやドラッグによる並び順も使い、自分が見る順序を整えられます。これらの操作はBacklog側のステータスや期限を書き換えません。

複数の顧客を担当している場合も、スペースをまたいで今日の仕事を整理できます。分類を増やしたくなったら、個人タグと優先順位の使い分けも参考にしてください。
