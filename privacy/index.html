IssueDockは、利用者が登録したBacklogスペースの課題を一画面へ集約し、端末内とChrome同期で個人的に整理するためのChrome拡張です。本ポリシーは無料ベータ版と、同じChrome Web Store拡張IDで提供するサブスクリプション版に適用します。

1. 取り扱う情報

IssueDockは次の情報を取り扱います。

  • 利用者が入力したBacklogスペースURLとAPIキー
  • Backlog APIから取得した接続ユーザー、参加プロジェクト、課題、課題本文、コメント、添付情報、同期状態
  • IssueDock内で設定した個人ステータス、今日、待ちの再確認日、並び順、ピン、タグ、設定
  • 無料トライアルまたは契約のために利用者がExtensionPayへ入力するメールアドレス
  • ExtensionPayから取得するトライアル開始日時、契約状態、契約プラン、解約予定日時

2. 利用目的

これらの情報は、登録したBacklogスペースの課題を取得・表示し、複数スペースを横断して検索・整理し、利用者の端末間で個人整理データを同期し、無料トライアルと有料契約の利用権を確認するためにだけ使用します。

3. 保存先

データ保存先PC間同期
接続、プロジェクト、課題、課題詳細、同期状態Chrome拡張のIndexedDBしない
個人ステータス、タグ、設定chrome.storage.syncChrome同期が有効な場合のみ
APIキーPBKDF2-SHA-256 + AES-256-GCMで暗号化したcredential envelope利用者がChrome同期を選択した場合、暗号文のみ
復号済みAPIキーchrome.storage.localまたはchrome.storage.sessionしない
同期用パスフレーズ保存しないしない
ExtensionPayの利用者識別情報・契約状態ExtensionPayおよびchrome.storage.syncChrome同期が有効な場合
IssueDockのオフライン利用権キャッシュchrome.storage.localしない
カード・決済情報StripeIssueDockには保存しない

Chrome Storageは拡張の信頼されたコンテキストだけから参照できるよう制限します。IssueDockはExtensionPay上のIssueDock専用画面に限ってcontent scriptを実行し、英語の案内文、見出し、ボタン、プレースホルダーを日本語表示へ置換します。フォーム値、決済処理、メールアドレス、契約情報を読み取ったり送信したりしません。その他の閲覧中のWebページへコードやDOMを注入しません。

4. 外部通信と共有

  • IssueDockは、利用者が登録しChrome権限を許可したBacklog APIへHTTPSで通信します。
  • 無料トライアル、契約、別PCでのログイン、契約管理のためExtensionPayへ通信します。ExtensionPayは利用者のメールアドレスと利用権情報を取り扱います。
  • 支払いはStripeの画面で行われます。カード・決済情報はStripeが取り扱い、IssueDockから参照しません。
  • 課題、APIキー、個人整理データをIssueDock運営者のサーバー、ExtensionPay、Stripeへ送信しません。
  • 匿名利用状況計測、広告SDK、外部エラー監視を使用しません。
  • 情報を販売、広告利用、または第三者提供しません。
  • 法令に基づく場合を除き、人が利用者のBacklogデータを閲覧することはありません。

IssueDockによる情報の利用は、Chrome Web Store User Data PolicyのLimited Use要件に従います。

5. Chrome権限

  • storage: 暗号化した接続情報、個人整理データ、設定、ExtensionPayの利用者識別情報・契約状態およびIssueDockのオフライン利用権キャッシュの保存に使用します。
  • Backlogのhost permission: 利用者が接続時に入力したスペースのoriginについて、実行時に個別に要求します。全Webサイトへの恒久的なアクセスは要求しません。
  • ExtensionPayのIssueDock専用画面: https://extensionpay.com/extension/issue-dock/* で英語の操作案内を日本語表示へ置換するcontent scriptのためにだけ使用します。フォームや決済処理、利用者データにはアクセスしません。

6. JSONバックアップ

利用者が明示的に書き出した場合だけ、個人整理データと設定をJSONファイルへ保存します。APIキー、パスフレーズ、復号済みキー、課題本文、コメント、添付は含みません。

7. データの削除

  • 接続解除: 対象スペースの接続情報、復号済みAPIキー、端末キャッシュ、サイト権限を削除します。個人タグ等は再接続に備えて保持します。
  • 同期リセット: 対象接続の暗号文をChrome同期から削除し、この端末だけの暗号化保存へ切り替えます。
  • アンインストール: Chromeが拡張に属する端末データと同期データを削除します。必要な個人整理データは事前にJSONバックアップしてください。
  • 契約の解約: IssueDock内の「プランと利用状況」からExtensionPay・Stripeの契約管理画面を開きます。解約してもBacklog接続、課題キャッシュ、個人整理データは削除しません。

8. セキュリティ

APIキーはPBKDF2-SHA-256で導出した鍵とAES-256-GCMで暗号化します。APIキーの平文とパスフレーズを同期データ、JSONバックアップ、ログへ含めません。Backlog API通信ではcredentials: omitとcache: no-storeを指定します。

ExtensionPayの通信に失敗した場合、確認済みトライアルは本来の終了日時まで、確認済み有料契約は最後の成功確認から最大72時間だけ利用できます。オフライン利用権キャッシュにメールアドレスとカード情報は保存しません。

9. 変更

情報の取り扱いを変更する場合は、本ポリシー、Chrome Web Store掲載情報、IssueDock内の説明を更新します。新しい目的でデータを取り扱う場合は、適用前に明示し、必要な同意を取得します。

10. 問い合わせ

問い合わせとベータ版の不具合報告は、support@issue-dock.com で受け付けます。
