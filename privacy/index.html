IssueDockは、利用者が登録したBacklogスペースの課題を一画面へ集約し、端末内とChrome同期で個人的に整理するためのChrome拡張です。本ポリシーは、14日間の無料トライアルと有料サブスクリプションを含む、Chrome Web Storeで提供するIssueDockに適用します。

1. 取り扱う情報

IssueDockは次の情報を取り扱います。

  • 利用者が入力したBacklogスペースURLとAPIキー
  • Backlog APIから取得した接続ユーザー、参加プロジェクト、課題、課題本文、コメント、添付情報、同期状態
  • IssueDock内で設定した個人ステータス、今日、待ちの再確認日、並び順、ピン、タグ、設定
  • アカウント作成・ログイン・トライアル・契約管理のために利用者が入力するメールアドレス
  • 本人確認日時、端末名・最終利用日時、認証用トークンのダイジェスト、認証セッション、トライアル・無料利用権・契約状態
  • Stripeの顧客・契約・料金識別子、決済状態、支払い失敗日時と72時間の猶予期限、解約状態、返金および管理操作の記録
  • 不正利用防止のためのメールアドレスと接続元IPアドレスのハッシュ値、試行回数、有効期限
  • APIのrequest ID、route、応答状態、処理時間、エラーコード等の運用ログ

2. 利用目的

Backlog関連情報と個人整理データは、登録したスペースの課題を取得・表示・整理し、利用者の端末間で同期するために使用します。アカウント・契約関連情報は、パスワードレスログイン、本人確認、トライアルの重複防止、複数端末での利用、利用権の判定、請求・解約・返金、問い合わせ対応、不正利用防止、障害調査および法令対応のために使用します。

Chrome Storageは拡張の信頼されたコンテキストだけから参照できるよう制限します。Backlogの課題、APIキー、個人整理データはIssueDockのサーバー、Cloudflare、Resend、Stripeへ送信しません。

4. 外部通信と共有

  • 利用者が登録しChrome権限を許可したBacklog APIへHTTPSで通信します。
  • ログイン、トライアル、利用権・契約管理のためIssueDock APIへ通信し、Cloudflare WorkersとD1を利用します。
  • 本人確認等の取引メールはResendを通じて送信します。このため、送信先メールアドレス、認証用URL、メール件名および本文をResendへ送信します。
  • 購入・契約管理はStripeの画面で行われます。Stripeの画面で入力するカード情報その他の決済・請求情報はStripeが取り扱い、IssueDockから参照・保存しません。
  • 課題、APIキー、個人整理データをIssueDock運営者のサーバー、Cloudflare、Resend、Stripeへ送信しません。
  • 広告SDK・行動解析は使用しません。障害検知のため、個人情報、query string、認証情報、本文を含めない運用ログと集計指標を使用します。
  • 情報を販売または広告利用しません。法令に基づく場合を除き、本項の委託先以外の第三者へ提供しません。

IssueDockによる情報の利用は、Chrome Web Store User Data PolicyのLimited Use要件に従います。

5. Chrome権限

  • storage: 暗号化した接続情報、個人整理データ、設定、IssueDockの利用者識別子およびオフライン利用権キャッシュの保存に使用します。
  • Backlogのhost permission: 利用者が接続時に入力したスペースのoriginについて、実行時に個別に要求します。全Webサイトへの恒久的なアクセスは要求しません。

6. JSONバックアップ

利用者が明示的に書き出した場合だけ、個人整理データと設定をJSONファイルへ保存します。APIキー、パスフレーズ、復号済みキー、課題本文、コメント、添付は含みません。

7. データの保持と削除

  • 接続解除: 対象スペースの接続情報、復号済みAPIキー、端末キャッシュ、サイト権限を削除します。個人タグ等は再接続に備えて保持します。
  • 同期リセット: 対象接続の暗号文をChrome同期から削除し、この端末だけの暗号化保存へ切り替えます。
  • アンインストール: Chromeが拡張に属する端末データと同期データを削除します。IssueDockサーバーのアカウント・契約記録はアンインストールだけでは削除されません。
  • 契約の解約: IssueDock内からStripeの契約管理画面を開きます。解約してもBacklog接続、課題キャッシュ、個人整理データおよびアカウント情報は削除しません。
  • アカウント情報の削除: support@issue-dock.comへ依頼してください。本人確認後、メールアドレス、認証セッション、端末情報を原則30日以内に削除します。決済・返金・監査記録は、法令対応、不正防止または紛争解決に必要な期間に限り保持する場合があります。

API運用の生ログは30日で削除し、個人を識別できない可用性・件数・遅延の集計値は13か月保持します。

8. セキュリティ

APIキーはPBKDF2-SHA-256で導出した鍵とAES-256-GCMで暗号化します。APIキーの平文とパスフレーズを同期データ、JSONバックアップ、IssueDockサーバー、運用ログへ含めません。認証tokenは平文で保存せず、digestを保存します。

運用ログにはroute template、応答状態、処理時間、エラーコード、request IDを記録し、query string、Authorization、Cookie、token、メールアドレス、端末名、Stripe payload、Backlogデータを記録しません。Cloudflare、ResendまたはStripeの障害時は、確認済みの利用権を最大72時間、署名付きのオフライン利用権キャッシュで継続する場合があります。

9. 変更

情報の取り扱いを変更する場合は、本ポリシー、Chrome Web Store掲載情報、IssueDock内の説明を更新します。新しい目的でデータを取り扱う場合は、適用前に明示し、必要な同意を取得します。

10. 問い合わせ

問い合わせと不具合報告は、support@issue-dock.com で受け付けます。
