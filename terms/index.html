1. 規約の適用範囲

本規約は、IssueDockの利用に関する利用者と運営者との間の一切の関係に適用されます。利用者は、本規約および本規約から参照する各方針を確認し、同意したうえでIssueDockを利用するものとします。

2. IssueDockのサービス内容

IssueDockは、利用者が登録した複数のBacklogスペースから課題情報を取得し、一つの画面で横断検索・閲覧・整理するためのChrome拡張です。個人ステータス、今日、ピン、タグなどの整理情報はIssueDock内に保存し、Backlog側の課題や運用ルールを変更しません。

3. 利用条件・対応環境

  • 利用者が正当に利用できるBacklogアカウント、BacklogスペースURLおよびAPIキーが必要です。
  • Googleがサポートしているデスクトップ版Google Chromeを利用できるWindows、macOS、LinuxおよびChromeOSに対応します。Android・iOSなどのモバイル環境には対応しません。
  • Google Chrome 102以上（最新版推奨）が必要です。Google Chrome以外のChromium系ブラウザは動作保証の対象外です。
  • Chrome同期を利用する機能には、同じGoogleアカウントでChrome同期を有効にした環境が必要です。
  • 未成年者は、法定代理人の同意を得たうえで利用してください。
  • IssueDockは主として日本語利用者向けに提供します。日本国外から利用する場合、利用者が現地法令への適合を確認するものとし、日本国外での利用可能性、表示、サポートまたは決済を保証しません。

4. 利用者の責任

利用者は、自らの責任で利用環境、Backlogアカウント、Googleアカウント、端末およびネットワークを管理し、所属組織の規程やBacklogの利用条件を守ってIssueDockを利用するものとします。IssueDockで表示した情報を利用して行う判断や操作についても、利用者が責任を負います。

5. Backlog APIキーなどの管理責任

利用者は、Backlog APIキーと同期用パスフレーズを自己の責任で適切に管理し、第三者への開示、貸与、共有を行わないものとします。APIキー、パスワード、カード番号をメールで運営者へ送信しないでください。漏えいまたは不正利用のおそれがある場合は、利用者自身で速やかにAPIキーの無効化・再発行など必要な措置を行ってください。

6. 禁止事項

利用者は、IssueDockの利用にあたり、次の行為をしてはなりません。

  • 法令、公序良俗、本規約または第三者サービスの規約に違反する行為
  • 第三者のアカウント、APIキー、データまたは権利を不正に利用する行為
  • IssueDockまたは関連サービスの運営、セキュリティ、ネットワークを妨害する行為
  • 不正アクセス、過度な負荷、脆弱性の悪用その他これらに準ずる行為
  • 法令で認められる範囲を超えて、IssueDockを複製、改変、解析または再配布する行為
  • 一つの契約を複数の無関係な利用者で共有する行為
  • 契約、認証情報または利用権を第三者へ譲渡、貸与または再販売する行為
  • IssueDock自体を第三者向けサービスとして再提供する行為
  • その他、運営者が合理的な理由により不適切と判断する行為

7. 知的財産権

IssueDockおよび公式サイトに関する著作権その他の知的財産権は、運営者または正当な権利者に帰属します。本規約は、利用者にIssueDockを本規約の範囲で利用する権利のみを許諾するもので、知的財産権を譲渡するものではありません。業務・商用目的での通常利用を認めます。同一の購入者は、ExtensionPayで購入時のメールアドレスを確認することで別の端末でも利用できますが、無関係な利用者との契約共有は認めません。複数のBacklogスペースを登録でき、現行実装にはプラン別の登録件数または機能制限を設けていません。利用者がBacklog上で取り扱うデータの権利は、各権利者に留保されます。

8. 有料プランの料金

有料プランは、月額250円（税込）と年額2,400円（税込）の二種類です。請求通貨は日本円です。いずれのプランでもすべての機能を利用でき、機能別のプラン差はありません。無料トライアルは14日間で、開始時のカード登録は不要、終了後の自動課金もありません。継続利用には利用者自身による有料プランの購入が必要です。インターネット接続に必要な通信料は利用者の負担で、その他の追加費用はありません。

9. 支払方法・支払時期

購入、購入済み利用者のログインおよび契約管理の画面はExtensionPayが提供し、カード決済はStripeが処理します。カード情報はStripeの画面で入力され、IssueDockから参照しません。初回料金は購入手続き完了時に、以後の料金は各契約期間の更新時に請求されます。Stripeの公開ビジネス名は「IssueDock」、カード明細書表記は「ISSUEDOCK」です。

10. サブスクリプションの自動更新

月額プランは1か月ごとに250円（税込）、年額プランは1年ごとに2,400円（税込）で自動更新されます。次回更新を止める場合は、更新処理の前に第11項の契約管理画面で解約手続きを完了してください。料金を変更する場合は原則として30日前までに通知し、通知後の次回更新以降に適用します。

11. 解約方法と解約の反映時期

IssueDock内の「プランと利用状況」で「契約・支払い方法を管理」を選ぶと、ExtensionPay・Stripeの契約管理画面が開きます。同画面で解約手続きを行い、IssueDockへ戻った後に「契約状態を再確認」を選んでください。解約手続き後も、支払済みの契約期間末日まで有料機能を利用できます。解約により次回以降の自動更新が停止され、契約期間の途中で利用を終了した場合も日割り返金は行いません。IssueDockには契約終了予定日を表示し、その日を過ぎると有料機能へのアクセスを停止します。

解約、トライアル終了または支払失敗によって、保存済みのBacklog接続、暗号化したAPIキー、課題キャッシュ、タグ、個人ステータス、今日、待ち、ピンおよび並び順は削除しません。再契約後は保存済みデータを維持したまま利用を再開できます。

12. 返金条件

デジタルサービスの性質上、購入者都合によるキャンセル・返金は原則として受け付けず、支払済み期間の未利用分の日割り返金も行いません。ただし、二重請求、誤課金、法令上返金が必要な場合は返金対象とします。IssueDock側の重大な不具合により主要機能を利用できず、合理的な期間内に解消できない場合は個別に対応します。

返金を申請する場合は、決済日、金額、決済に使用したメールアドレスおよび申請理由をsupport@issue-dock.comへ送ってください。カード番号、パスワードまたはBacklog APIキーは送信しないでください。確認後に返金可否を回答し、承認した場合は速やかに処理します。実際の着金日はStripeおよびカード会社の処理期間によります。

13. サービスの変更・中断・終了

運営者は、保守、セキュリティ上の対応、法令・外部サービスの変更、不可抗力その他合理的な理由がある場合、IssueDockの全部または一部を変更、中断または終了することがあります。利用者への影響が大きい場合は、可能な限り事前に公式サイト、Chrome Web Store掲載情報またはIssueDock内で知らせます。

14. 保証の否認

運営者は、IssueDockについて、特定目的への適合性、正確性、完全性、継続性、可用性、第三者サービスとの恒久的な互換性または不具合がないことを保証しません。ただし、法令により排除できない保証や責任を除きます。

15. 損害賠償・責任制限

運営者の通常の軽過失によって利用者に損害が生じた場合、賠償対象は現実に発生した直接かつ通常の損害に限り、逸失利益、間接損害、特別損害およびデータ消失による派生損害は、法令上認められる範囲で対象外とします。この場合の賠償上限は、損害発生前12か月間に利用者がIssueDockへ実際に支払った料金総額と1万円のいずれか高い額です。

運営者の故意または重過失による場合、または消費者契約法その他の強行法規により免責・責任制限が認められない場合には、前項の制限を適用しません。

16. 外部サービスとの関係

IssueDockは株式会社ヌーラボの公式製品ではありません。Backlogは株式会社ヌーラボの商標または登録商標です。 IssueDockは、株式会社ヌーラボとの提携、承認または推奨を示すものではありません。

IssueDockはBacklog API、Google Chrome、Chrome同期、Chrome Web Storeおよび外部決済サービスに依存します。これら第三者サービスの障害、仕様変更、利用制限または提供終了により、IssueDockの機能が制限される場合があります。第三者サービスには各提供者の利用条件が適用されます。

17. プライバシーポリシー

IssueDockにおける情報の取り扱い、保存先、外部通信、Chrome権限および削除方法は、プライバシーポリシーに定めます。

18. 規約変更時の通知方法

運営者は、法令に従い本規約を変更することがあります。変更内容と適用日は、公式サイトへの掲載、Chrome Web Store掲載情報、IssueDock内の通知その他適切な方法で通知します。利用者に重大な不利益を与える変更については合理的な予告期間を設けます。料金変更は原則として30日前までに通知し、通知後の次回更新以降に適用します。ただし、法令対応、セキュリティ対応その他の緊急対応では、事前通知期間を短縮し、または事後に通知することがあります。

19. 準拠法・合意管轄

本規約の準拠法は日本法とし、IssueDockに関して生じた紛争については、東京地方裁判所または東京簡易裁判所を第一審の専属的合意管轄裁判所とします。法令により別の管轄が認められる場合は、その法令に従います。

20. 問い合わせ先

本規約またはIssueDockに関する問い合わせは、support@issue-dock.com へお送りください。メールは24時間受け付け、通常対応は日本時間の平日10:00～17:00（土曜日、日曜日、日本の祝日、年末年始を除く）、初回返信は原則3営業日以内です。内容や調査状況により回答に時間がかかる場合があります。APIキー、パスワード、カード番号をメールに記載しないでください。
