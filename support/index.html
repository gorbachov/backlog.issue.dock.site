1. サポート対象

IssueDockのインストール、初期設定、Backlogスペースとの接続、画面の使い方、同期、データの取り扱い、不具合、セキュリティ上の問題、および提供開始後の契約・解約・返金に関する問い合わせを受け付けます。

IssueDockは株式会社ヌーラボの公式製品ではありません。 Backlog本体の仕様、契約、障害またはアカウント管理については、株式会社ヌーラボの案内をご確認ください。Backlogは株式会社ヌーラボの商標または登録商標です。

2. 問い合わせ先・対応時間

メール: support@issue-dock.com（24時間受付）

  • 通常対応: 日本時間の平日10:00～17:00
  • 休業日: 土曜日、日曜日、日本の祝日、年末年始
  • 初回返信目安: 原則3営業日以内
  • 電話サポート: 実施していません

内容や調査状況により回答に時間がかかる場合があります。臨時休業がある場合は公式サイト等で案内します。製品サポートはメールで受け付けています。特定商取引法に基づく表記の電話番号は、法令上・事業者連絡先として掲載しているもので、電話サポート窓口ではありません。

3. 問い合わせ時に記載してほしい情報

  • 問い合わせの種類（使い方、不具合、契約、セキュリティなど）
  • IssueDockのバージョン
  • Chromeのバージョンと利用OS
  • 問題が起きるまでの操作手順、期待した結果、実際の結果
  • 表示されたエラーメッセージ（秘密情報を除く）
  • 問題が継続しているか、最初に発生した時期

Backlog APIキー、パスワード、カード番号は送信しないでください。課題内容、コメント、利用者名などの機密情報が写ったスクリーンショットは、必要箇所をマスクしてから添付してください。

4. よくある質問

BacklogのデータはIssueDock運営者へ送信されますか？

送信しません。IssueDockは、利用者が登録しChrome権限を許可したBacklog APIへ直接通信します。課題、APIキー、個人整理データをIssueDock運営者のサーバーへ送信しません。

Backlog側の課題を書き換えますか？

個人ステータス、今日、ピン、タグなどの整理情報はIssueDock内に保存し、Backlog側の課題を変更しません。

別のPCでも整理状態を使えますか？

同じGoogleアカウントでChrome同期を利用している場合、個人整理データと暗号化した接続情報を同期できます。課題キャッシュと復号済みAPIキーはPC間で同期しません。有料契約は、同じ購入者がExtensionPayで購入時のメールアドレスを確認することで別のPCでも利用できます。

株式会社ヌーラボの公式サービスですか？

いいえ。IssueDockは株式会社ヌーラボの公式製品ではなく、同社との提携、承認または推奨を示すものではありません。

5. インストール方法

IssueDockのChrome Web Store Item IDは ciglfijkdakeeaahlbnhpbaalljbnepd で、Chrome Web Store掲載ページは現在Trusted Tester向けです。一般向け提供開始日は [要決定：有料版提供開始日] です。Googleがサポートしているデスクトップ版Google Chromeを利用できるWindows、macOS、LinuxおよびChromeOSに対応し、Android・iOSなどのモバイル環境には対応しません。Google Chrome 102以上（最新版推奨）が必要で、Google Chrome以外のChromium系ブラウザは動作保証の対象外です。利用可能になった掲載ページをChromeで開き、「Chromeに追加」を選び、表示される権限を確認してインストールしてください。配布元とItem IDが一致することを確認してください。

6. Backlogスペースの接続方法

  1. 利用者が正当に利用できるBacklogスペースURLとAPIキーを用意します。
  2. IssueDockでスペースURLとAPIキーを入力し、接続を確認します。
  3. Chromeが接続先スペースのoriginに対する権限を求めた場合は、対象が意図したスペースであることを確認して許可します。
  4. APIキーの保存方法を選び、Chrome同期を利用する場合は同期用パスフレーズを設定します。

組織の管理者がAPI利用やChrome拡張の導入を制限している場合は、所属組織の規程に従ってください。

7. APIキーの取り扱い

  • 利用者自身の責任で発行・保管し、必要最小限の人だけが取り扱ってください。
  • メール、チャット、スクリーンショット、ログまたはJSONバックアップに記載しないでください。
  • 漏えいまたは不正利用のおそれがある場合は、Backlog側で速やかにAPIキーを無効化・再発行してください。
  • IssueDockの接続解除では、対象接続の復号済みAPIキーと端末内キャッシュを削除します。

8. Chrome権限の説明

  • storage: 暗号化した接続情報、個人整理データ、設定の保存に使用します。
  • Backlogのhost permission: 利用者が入力したスペースのoriginについて、接続時に個別に要求し、Backlog APIへ通信するために使用します。

IssueDockは全Webサイトへの恒久的なアクセスを要求しません。ExtensionPay上のIssueDock専用画面（https://extensionpay.com/extension/issue-dock/*）に限ってcontent scriptを実行し、英語の案内文、見出し、ボタンおよびプレースホルダーを日本語表示へ置換します。フォーム値、決済処理、メールアドレスまたは契約情報を読み取ったり送信したりせず、その他の閲覧中ページへコードやDOMを注入しません。

10. 同期・暗号化

APIキーは、PBKDF2-SHA-256で導出した鍵とAES-256-GCMで暗号化します。Chrome同期を選択した場合も同期するのは暗号文だけで、APIキーの平文と同期用パスフレーズは同期しません。新しいPCでは、利用者が同期用パスフレーズを入力して接続情報を復号します。

11. 不具合発生時の確認事項

  1. ChromeとIssueDockを再起動し、同じ操作で再現するか確認します。
  2. ネットワーク接続と、対象Backlogスペースをブラウザで利用できるか確認します。
  3. スペースURLが正しいか、APIキーが有効か、対象スペースのChrome権限が許可されているか確認します。
  4. ChromeとIssueDockのバージョン、利用OS、エラーメッセージ、再現手順を控えます。
  5. 改善しない場合は、秘密情報を除いた確認結果をsupport@issue-dock.comへ送ります。

再インストールやデータ削除を行うと端末内データが失われる場合があります。必要な個人整理データは、可能であれば事前にJSONバックアップしてください。

12. 契約状況の確認方法

IssueDock内の「プランと利用状況」で、無料トライアル、月額・年額の契約状態、支払失敗、解約予定日または契約終了を確認できます。購入後、別PCでのログイン後または支払方法の更新後は、IssueDockへ戻るか「契約状態を再確認」を選んでください。起動中は30分ごとにも再確認します。購入・ログイン・契約管理の画面はExtensionPayが提供し、決済とカード情報はStripeが取り扱います。

13. 解約方法

「プランと利用状況」で「契約・支払い方法を管理」を選び、ExtensionPay・Stripeの契約管理画面で解約手続きを行います。IssueDockへ戻り「契約状態を再確認」を選んでください。解約手続き後も、支払済みの契約期間末日まで有料機能を利用できます。IssueDockには契約終了予定日を表示し、その日を過ぎると有料機能へのアクセスを停止します。解約により次回以降の自動更新が停止され、契約期間の途中で利用を終了した場合も日割り返金は行いません。

解約、トライアル終了または支払失敗によって、保存済みのBacklog接続、暗号化したAPIキー、課題キャッシュおよび個人整理データは削除しません。再契約後は保存済みデータを維持したまま利用を再開できます。

14. 返金に関する案内

デジタルサービスの性質上、購入者都合によるキャンセル・返金は原則として受け付けず、支払済み期間の未利用分の日割り返金も行いません。二重請求、誤課金、法令上返金が必要な場合は返金対象です。IssueDock側の重大な不具合により主要機能を利用できず、合理的な期間内に解消できない場合は個別に対応します。

返金申請はsupport@issue-dock.comへ、決済日、金額、決済に使用したメールアドレスおよび申請理由を記載して送ってください。カード番号、パスワードまたはBacklog APIキーは送信しないでください。確認後に返金可否を回答し、承認した場合は速やかに処理します。実際の着金日はStripeおよびカード会社の処理期間によります。条件の全文は利用規約と特定商取引法に基づく表記をご確認ください。

15. セキュリティ上の問題の報告

脆弱性、APIキーの意図しない表示、想定外の外部通信など、セキュリティ上の問題を発見した場合は、件名に「IssueDock セキュリティ報告」と記載してsupport@issue-dock.comへお知らせください。

問題の概要、影響、再現手順、IssueDock・Chromeのバージョンを、秘密情報を含めずに記載してください。APIキー、パスワード、カード番号、実際の課題内容または攻撃に利用できる不要な個人情報は送信しないでください。
