4. よくある質問

BacklogのデータはIssueDock運営者へ送信されますか？

送信しません。IssueDockは、利用者が登録しChrome権限を許可したBacklog APIへ直接通信します。課題、APIキー、個人整理データをIssueDock運営者のサーバーへ送信しません。

Backlog側の課題を書き換えますか？

個人ステータス、今日、ピン、タグなどの整理情報はIssueDock内に保存し、Backlog側の課題を変更しません。

別のPCでも整理状態を使えますか？

同じGoogleアカウントでChrome同期を利用している場合、個人整理データと暗号化した接続情報を同期できます。課題キャッシュと復号済みAPIキーはPC間で同期しません。

株式会社ヌーラボの公式サービスですか？

いいえ。IssueDockは株式会社ヌーラボの公式製品ではなく、同社との提携、承認または推奨を示すものではありません。

5. インストール方法

IssueDockはChrome Web Storeでの無料ベータ公開に向けて準備中です。公開URL、インストール手順および提供開始時期は [要決定] です。公開後は正規のChrome Web Store掲載ページからインストールし、配布元を確認してください。

6. Backlogスペースの接続方法

  1. 利用者が正当に利用できるBacklogスペースURLとAPIキーを用意します。
  2. IssueDockでスペースURLとAPIキーを入力し、接続を確認します。
  3. Chromeが接続先スペースのoriginに対する権限を求めた場合は、対象が意図したスペースであることを確認して許可します。
  4. APIキーの保存方法を選び、Chrome同期を利用する場合は同期用パスフレーズを設定します。

組織の管理者がAPI利用やChrome拡張の導入を制限している場合は、所属組織の規程に従ってください。

7. APIキーの取り扱い

  • 利用者自身の責任で発行・保管し、必要最小限の人だけが取り扱ってください。
  • メール、チャット、スクリーンショット、ログまたはJSONバックアップに記載しないでください。
  • 漏えいまたは不正利用のおそれがある場合は、Backlog側で速やかにAPIキーを無効化・再発行してください。
  • IssueDockの接続解除では、対象接続の復号済みAPIキーと端末内キャッシュを削除します。

8. Chrome権限の説明

  • storage: 暗号化した接続情報、個人整理データ、設定の保存に使用します。
  • Backlogのhost permission: 利用者が入力したスペースのoriginについて、接続時に個別に要求し、Backlog APIへ通信するために使用します。

IssueDockは全Webサイトへの恒久的なアクセスを要求せず、content scriptを使用して閲覧中ページへコードやDOMを注入しません。

9. データの保存先

データ保存先PC間同期
接続、プロジェクト、課題、課題詳細、同期状態Chrome拡張のIndexedDBしない
個人ステータス、タグ、設定chrome.storage.syncChrome同期が有効な場合のみ

詳しくはプライバシーポリシーの「保存先」をご覧ください。

10. 同期・暗号化

APIキーは、PBKDF2-SHA-256で導出した鍵とAES-256-GCMで暗号化します。Chrome同期を選択した場合も同期するのは暗号文だけで、APIキーの平文と同期用パスフレーズは同期しません。新しいPCでは、利用者が同期用パスフレーズを入力して接続情報を復号します。

11. 不具合発生時の確認事項

  1. ChromeとIssueDockを再起動し、同じ操作で再現するか確認します。
  2. ネットワーク接続と、対象Backlogスペースをブラウザで利用できるか確認します。
  3. スペースURLが正しいか、APIキーが有効か、対象スペースのChrome権限が許可されているか確認します。
  4. ChromeとIssueDockのバージョン、利用OS、エラーメッセージ、再現手順を控えます。
  5. 改善しない場合は、秘密情報を除いた確認結果をsupport@issue-dock.comへ送ります。

再インストールやデータ削除を行うと端末内データが失われる場合があります。必要な個人整理データは、可能であれば事前にJSONバックアップしてください。
