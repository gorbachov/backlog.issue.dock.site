## 構成判断

横断表示はヒーローで紹介し、色分けされた2スペース・課題一覧・詳細を提示。機能紹介は6つに集約する。

1. 今日・次・待ち・あとで／タグ／ピンを個人整理へ集約。
2. 検索・絞り込み。
3. 課題詳細・コメント。
4. スペース別カラーテーマ。
5. 同期・複数端末（キャッシュは端末ごとである点を説明）。
6. プランと利用状況（架空状態の例と明記し、条件は法務ページへリンク）。

WebP、quality 90。日本語altとwidth/height、下部画像はlazy loading。500px幅ではヒーローを部分拡大し、検索・テーマ・同期には別画像を使用。撮影後の変更は切り抜き・圧縮のみで、UI描き直しや架空合成は行っていない。

## 撮影の再現

1. 拡張リポジトリの上記コミットを別の安全な作業フォルダにチェックアウトする。
2. 依存関係を導入し `WXT_ISSUEDOCK_E2E=1 pnpm build`。本番設定・実プロフィール・実データは利用しない。
3. サイト側で `npm install`、`npx playwright install chromium`。
4. `ISSUEDOCK_DEMO_EXTENSION=/absolute/path/to/.output/chrome-mv3 npx playwright test --config scripts/capture/playwright.config.ts`。
5. `test-results/store/`を確認し、WebPへ変換。配布ZIPのCSS一致、個人情報・秘密情報なしを再確認する。

#6はユーザーのデザイン・内容確認待ち。明示承認前にマージ・main更新・デプロイをしない。

## Cカラムの再撮影

ユーザー確認を受け、通常の境界ドラッグ操作でCカラムを約540pxに拡大して再撮影。「今日」「ピン留め」「完了後も残す」の文字が各1行であることをブラウザ上の文字領域で検査。ヒーロー・個人整理・課題詳細を差し替え、原寸属性も更新。製品CSSの変更なし。
