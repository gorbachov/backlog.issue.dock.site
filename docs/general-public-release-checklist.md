## 推奨公開順序

1. 法的な日付を確定し、サイトPRへ反映する。
2. サイトのリリース検査と目視確認を完了する。
3. サイトPRを`main`へマージし、デプロイ完了と各ページの反映を確認する。
4. Chrome Web Storeで`0.1.0.0`を手動公開する。
5. 一般ユーザーとしてChrome Web Storeからインストールし、トライアル開始から契約管理までのスモークテストを行う。

サイト反映とストア公開の間隔は短くする。サイトが先に反映された間、ストアページが一般ユーザーに見えない可能性があるため、同一作業枠で実施する。

## ロールバック判断

- 認証・利用権判定・決済に広範な不具合がある場合は、新規購入導線を止め、状況を公式サイトへ掲示する。
- 誤課金または利用権の誤停止が疑われる場合は、StripeとD1の状態を照合し、返金等の操作は権限を付与された管理者だけが行う。
- 拡張の問題はChrome Web Storeの公開停止・修正版審査、サイトの問題はサイトPRのrevertを個別に判断する。
